# Simple Calculator

A simple calculator written in Python that can perform:

- Addition
- Subtraction
- Multiplication
- Division

## How to Run

Run the program:

```bash
python main.py
```

## Example

```text
To start the program, type: start

Please select your operation:

1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter your choice: 1
Enter first number: 12
Enter second number: 12

The result is: 24
```
